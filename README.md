# NeuroMesh v2.0.0

Децентрализованная P2P-инфосеть с ИИ-иммунитетом.

## Сборка Android
    bash scripts/build-rust-android.sh
    cd flutter_app && flutter build apk --release --split-per-abi

## Сборка Windows
    pwsh scripts/build-rust-windows.ps1
    cd flutter_app && flutter build windows --release
